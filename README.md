# Projeto de Acelração de Carreira - Classificando Pacientes com risco de AVC
PAC ou Projeto de Aceleração de Carreira, é um programa dentro do bootcamp da TripleTen para impulsionar a carreira dos alunos. Nesse projeto desenvolvi um algoritmo de aprendizado de máquina que classifica o grau de risco de um paciente ser acometido por um AVC baseado em seus dados.
